# 小橘 Live2D 实施 PRD v2.2

> 状态：2026-07-19 流程复盘修订。当前有效阶段回退到 **X3 身份锁定目标图与生产线稿复审**。X4-X6 的历史许可因前置视觉证据被后续拼装否定而暂停，不授权继续材质分层、网格、参数、Physics、Cubism 或运行时。

## 1. 文档边界

通用 `rig-live2d-pet` Skill 规定任何角色都适用的 Gate、独立材质、ArtMesh、节点树、主动 Motion、弹性、Action Tracer 和运行时 QA。本 PRD 只规定小橘的身份、猫科结构、星球接触、登录动作、参数目标和小橘专用验收证据。

若本 PRD、历史合同或脚本与当前 Gate 文件冲突，以 `live2d/blueprints/v2-artifact-disposition.json` 和最新用户视觉结论为准。

## 2. 参考流程与本轮修正

用户指定参考《Live2D动画引擎的图形学原理及实现》（`https://zhuanlan.zhihu.com/p/383268858`）。本文采用其中可验证的依赖顺序：

```text
独立图层 PNG
  -> 每个实际图层自己的三角网格
  -> 图层唯一主节点及父子骨架
  -> 节点/顶点变换与主动动画
  -> 软组织顶点弹性
  -> Action Tracer
```

文章中的渲染实现、扫描线和 Bowyer-Watson 细节是原理参考，不等同于 Cubism 的完整产品规范；本项目仍需遵守 Cubism、目标运行时和用户视觉 Gate。

本轮失败暴露了四条必须加入 PRD 的规则：

1. “透明 PNG 数量正确”“重叠像素非零”“网格覆盖率通过”都不能证明还是同一只小橘。
2. 不得一次生成一板互不共享身体坐标的零件，再靠人工缩放、旋转和位置猜测拼成角色。
3. 不能把“生成完图层后再拼回比较”当作主要纠错机制；届时才发现误差，已经太晚。
4. 目标彩图通过后，必须先建立与其像素配准的生产线稿、语义边界、隐藏延伸和全画布图层遮罩，并先用平涂遮罩证明可无误重组。
5. 每个生成/修复图层只能在已批准遮罩内部填充材质，必须保留回到母版的精确身体空间变换；生成不得重新决定轮廓和比例。
6. 任一后续预览否定身份、比例或材质连续性时，必须回退到最早失效 Gate；历史用户许可不得继续掩盖失效证据。

## 3. 权威输入

### 3.1 可作为当前权威依据

- `three-view-preview.png`：小橘坐姿身份、脸部、毛色、花纹、头身比例和三视图一致性的最高视觉权威。
- `live2d/x1/x1-canonical-body-contract.json`：同名解剖点、近似 3D 骨架、固定骨段和质量块的工程依据。
- `live2d/x2/x2-pose-solve-contract.json`：遮眼链、接触、支撑、重心、物理力矩与控制力矩的工程依据。
- 原登录场景与 `planet-scene-source/`：摄像机、构图、星球接触意图和氛围依据。

### 3.2 只能作为条件参考

- `live2d/x5/qa/x5-actual-xiaoju-spread-pose-three-view.png`：可参考展开姿势和用户所说的“之前的小橘”，但其合同仍标记为 candidate，不能直接作为最终 PSD 或图层母版。
- X3 块面、大字型草图、X4 语义列表：可参考结构和拆层意图，不证明最终身份或材质成立。
- X5 网格、节点、力矩和弹性合同：可复用字段、算法和 QA 方法；其具体顶点、坐标和图层绑定不得进入生产。

### 3.3 禁止作为生产输入

- v5 混合身体、`parts-v5`、旧登录头部和旧 `.cmo3/.moc3` 的可见材质。
- X5 的 126 个遮罩切片、63 个生成细层及其网格。
- X6 v1-v16 的可见切片、隐藏填充、生成零件、动作组拼装和最终 v16 三视图拼装。
- 任何只存在于临时 imagegen 输出、未进入合同且未通过视觉审核的生成板。

## 4. 目标模型

- `XiaojuRoot`：从耳尖到尾尖的一只连续小橘，包含头脸、颈胸、四肢、四爪、腹部、骨盆、尾巴和所有默认隐藏结构。
- `PlanetRoot`：完整星球，包含后层、表面、前景边缘、接触阴影、漂浮、微旋转和遮挡区域。
- 两者必须可独立审计、开关和驱动。最终采用双 Root 还是两个模型，留到 X8 运行时试片决定。

首批主动动作仍为 `idle`、邮箱聚焦、密码遮眼进入/保持/退出。眨眼、目光、呼吸、耳朵、尾巴、胡须和身体回稳属于独立或次级通道。不得使用整图切换、DOM 解剖 PNG 或 CSS 关节动画。

## 5. 阶段与 Gate

### X0：冻结身份和动作范围

登记权威图、目标动作、禁止项、三视图风险和星球关系。任何新生成素材必须声明用于身份、姿势、隐藏补全还是技术示意，不能混用。

### X1：统一身体

在三视图标注头骨、下颌、颈根、肩胛、肩、肘、腕、爪心、肋笼、腹部、骨盆、髋、膝、跗和尾链同名点。建立一套近似 3D 骨架、固定骨段长度、关节范围、左右/深度关系和头、肋笼、腹部、骨盆质量块。

**Gate：**同一身体能回投解释三视图；不得为展开姿势重新发明另一只猫。

### X2：支撑、遮眼与力矩预演

明确胸腹—星球接触带、法线、摩擦、重心、支撑反力和前爪释放顺序。遮眼链固定为肩胛 → 肩 → 肘 → 腕 → 爪心，交付至少 41 点 `Rest -> Cover -> Rest` 连通块面。

骨段长度保持稳定；软组织视觉伸缩不得改写骨段。物理力矩 `r x F` / `J^T F` 负责方向和相对需求，控制力矩负责动作编排；两者都不替代正式图层或网格。

### X3：身份锁定的目标彩图与生产线稿

从 X1/X2 身体制作一只无星球遮挡、完整连续的小橘展开三视图目标彩图，再叠回星球检查。它必须统一：

- 正、侧、背的头身比、躯干长度、肩宽、髋宽、四肢长度/粗细和尾巴方向；
- 脸部、眼睛、耳朵、口鼻、奶油色区域、橘色花纹和毛流身份；
- 颈、腋下、髋、腹部、尾根及远侧肢体的完整隐藏结构；
- 同一身体空间原点、尺度、左右命名和地面/接触基准。

目标彩图通过身份复核后，在完全相同的画布、坐标、比例和同名点上制作生产线稿。线稿必须明确：

- 每个动作主体的可见边界和语义所有权；
- 颈、肩、肘、髋、膝、尾根和眼睑的隐藏延伸；
- 父子遮挡方向、Draw Order、关节轴和安全重叠带；
- 每个视图之间相同部件的对应关系。

随后从线稿确定性导出全画布遮罩，以平涂颜色按 Draw Order 重组。平涂重组必须在轮廓、部件归属和关节覆盖上与目标图完全对应，不能等生成材质后才发现结构误差。

**生成限制：**只允许针对同一坐标目标图做局部生成或 inpaint。不得生成一板零件后反向猜测角色比例。生产线稿和遮罩负责决定几何；后续生成只负责在锁定遮罩内补足毛发材质。

**Gate：**分两次审核但属于同一个 X3：

1. 并排显示 `three-view-preview.png`、展开目标彩图和关键比例/轮廓叠加，由用户通过身份与三视一致性。
2. 显示生产线稿、分区图、隐藏重叠图和平涂遮罩重组，由用户通过分层几何。

两项都通过才进入 X4。“先不管像不像”不能解释为目标图通过；“之后拼回再看”不能解释为线稿/遮罩通过。

### X4：完整独立材质分层

从 X3 批准的目标彩图、生产线稿和全画布遮罩逐个建立完整 PNG/PSD 材质层。遮罩、轮廓、Rest 位置和重叠几何已经在 X3 锁定；X4 只允许生成或绘制遮罩内部的可见/隐藏毛发材质，不得重新设计部件外形。每层必须记录源母版、源线稿、遮罩版本、身体空间原点、Rest 变换、语义所有权、隐藏补全、父层候选、Draw Order 和 Clipping 责任。

建议的动作主体保持克制：

- 头底、口鼻/下颌、左右耳、左右眼及眼睑；
- 连续躯干主体；
- 左右上臂、左右前臂连前爪；
- 左右大腿、左右小腿连后爪；
- 尾巴；
- 必要的颈胸毛、脸颊毛、胡须和完全隐藏过渡层作为子材质，不冒充独立动作主体。

眼睛层只包含眼球/虹膜/瞳孔/高光或合同明确的眼部子层，眼周脸毛归头底/眼眶遮挡。头底不得烘焙耳朵、眼球或嘴；身体底不得烘焙可移动四肢或尾巴。

**Gate 证据：**

1. 生成前的平涂遮罩重组已通过，且生成后的每层 alpha 与批准遮罩一致。
2. 只读取独立材质层重组 Rest，不使用整猫兜底。
3. 与 X3 母版做 alpha 轮廓、关键点、头身比、肢体宽度和身份并排检查；这里只验证材质没有破坏已锁定几何，不承担首次发现结构错误的职责。
4. 全部层单独图，以及头、耳、眼、嘴、四肢、尾巴大幅移开的隐藏补全图。
5. 语义污染为零；禁止重复耳、重复眼、第二肢体或背景。
6. 小幅拉开后关节仍重叠，但重叠像素只作为辅助指标。

### X5：每层 ArtMesh 与唯一主节点合同

只能对 X4 已批准的实际层建立网格。边界点来自真实 alpha/材质边界，内部点服务于曲率、关节、眼睑和软组织变形。采用三角图元和 Delaunay 原则形成非交叉三角网，并剔除封闭材质边界外三角形。

每个实际图层恰好一个主控制节点；辅助网格点、权重和弹性顶点不等于新增骨段。网格密度由动作主体和变形角色决定，不以“看起来专业”或覆盖率最大化为目标。

小橘主树目标：

```text
XiaojuRoot
  BodyRoot
    Ribcage / Abdomen / Pelvis
    Neck -> Head -> Eyes / Ears / Muzzle
    Scapula_L/R -> Shoulder -> Elbow -> Wrist -> ForePaw
    Hip_L/R -> Knee -> Hock -> HindPaw
    TailRoot -> TailMid -> TailTip

PlanetRoot
  PlanetBody -> PlanetBack / ContactShadow / PlanetFront / Decorations
```

**Gate：**边界外三角形为零、UV 有效、无翻面/破坏性狭长三角形、每层唯一主节点、父节点单一、刚性骨段极值长度稳定。有效网格不能补救无效图层。

### X6：参数、主动 Motion 与 Action Tracer

登录输入链：目标优先级 → 模型局部坐标 → 眼眶/指针安全区 → 速度限制和平滑 → 眼球先行 → 头部延迟跟随 → 身体低幅补偿 → Deformer 级联。

优先级：密码遮眼接触 > 明确交互目标 > 当前输入框 > 小橘附近指针 > idle。状态切换保留当前参数值和速度，不先跳回 Rest。

遮眼由肩、肘、腕、爪心和身体补偿主动曲线驱动；左右爪可低幅错时。Physics 不负责核心遮眼轨迹。必须验证 41 点往返、接触锁定、骨段长度、眼眶九点、五阶段眨眼和 `0 -> 1 -> 0` 连续性。

眼部参数沿用 v2.1 的通道意图：共同目光、左右开合、主眨眼、低幅会聚、眼睑跟随、瞳孔反应、高光视差、目光权重和眼—头补偿。具体范围必须重新基于有效 X4/X5 眼部层和网格测定，旧数值不得直接导入。

### X7：顶点级弹性与微动作

只在 X6 主动 Motion 通过后加入。解剖支点和骨段端点保持刚性；耳尖、尾中/尾尖、胡须、脸颊毛和胸腹软组织可按离主节点距离增加响应并调整阻尼。每条链记录输入、输出、刚度、阻尼、限幅和收敛时间，并交付冲击—回稳证据。

### X8：双 Root / 双模型运行时试片

比较单包双 Root 与小橘/星球双模型两案的遮挡、Clipping、参数同步、Physics、包体和性能。没有目标运行时证据前不锁定文件边界。

### X9：发布 QA

网页只驱动模型参数与模型级渲染顺序。证据必须包含 ArtMesh 极值、节点级联、遮眼往返、60 秒 idle、九点目光、眨眼慢放、状态中断、弹性回稳、星球接触、Cubism/目标 WebView 对照、构建和目标设备验证。

## 6. 当前 Gate 回退

本轮 v15/v16 证明：48 个独立透明层和 30 个非零重叠关节仍可重组出错误的头身比、短宽躯干、粗短四肢和坐姿侧面。侧/背头底还曾烘焙耳朵，说明语义所有权失效。用户明确指出拼装“和我们之前的不一样”。

因此：

- X1/X2 工程证据继续有效；
- X3 的历史“继续分层”许可不能替代身份锁定母版批准，当前 Gate 回退到 X3；
- X4-X6 历史产物全部停止作为生产候选；
- X5 网格/节点/弹性和 X6 参数只保留方法、合同字段或失败 QA；
- `gate3Approved=false`、`x4Authorized=false`、`gate4Approved=false`、`x5Authorized=false`、`gate5Approved=false`、`x6Authorized=false`、`gate6Approved=false`、`x7Authorized=false`。

下一步不是继续生成，而是先由用户审核本 PRD 与产物处置。只有用户明确恢复并批准新的 X3 身份锁定母版，才重新进入 X4。

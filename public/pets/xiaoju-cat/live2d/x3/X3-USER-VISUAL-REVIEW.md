## 为什么还不能直接分层

用户已经确认 X2 没什么问题，可以继续。但根据当前 PRD 的知乎流程修正，正确顺序是：

1. X2 支撑/遮眼/力矩通过；
2. X3 生成完整连续大字型/展开三视图母版；
3. X3 视觉审核通过；
4. X4 才从批准母版生成细致分层图片；
5. X5 才基于真实图层边界做正式三角剖分和 ArtMesh。

因此“可以分层”在当前 Gate 下解释为：可以继续到分层前的 X3 母版阶段，但不能跳过 X3 直接拆层。

## X3 母版必须解决的问题

- 小橘正、侧、背三视图必须是一只完整连续的小橘，不是三张不同身体。
- 四肢、四爪、耳根、尾根、肩胛、胸腹、骨盆和背部隐藏结构必须补全。
- 体积必须保留幼猫圆润感，不能通过缩短骨段或压扁肋笼/腹部/骨盆来适配动作。
- 肩、肘、腕、髋、膝、跗、尾根和耳根周围要留出后续安全重叠区。
- 眼眶、眼球中心和遮眼目标区要清楚，但不能提前拆成正式眼部图层。

## 当前禁止

- 不生成正式分层图片；
- 不写 layer table；
- 不做正式 Delaunay/ArtMesh；
- 不进 PSD/Photoshop；
- 不进 Cubism；
- 不用旧 v5/v7 混合身体替代 X1/X2 批准身体。

## X3 审核问题

- 是否仍然像 `three-view-preview.png` 里的小橘？
- 正、侧、背是否能看成同一套身体和骨段长度？
- 隐藏前肢、肩胸连接、尾根、耳根和后肢是否足够连续？
- 后续如果拆层，关节和遮挡边是否有足够安全重叠？
- 是否有任何明显的体积塌陷、骨段伸缩、身份混合或姿势拼接？

只有这些都通过，才允许进入 X4 分层。

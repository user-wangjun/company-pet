# 小橘 Live2D v2 纠偏 PRD

> 状态：历史纠偏稿。生物力学止损结论继续有效；当前小橘实施方案已迁移到 `XIAOJU-LIVE2D-IMPLEMENTATION-PRD-v2.1.md`。

## 1. 结论

正式方案是“完整小橘 + 完整星球”，不是登录截图里几个可见部件。

- 小橘从耳尖到尾尖建立完整身体、完整隐藏结构和连续参数。
- 星球建立独立 Root、网格、漂浮和遮挡逻辑。
- 登录场景优先在一个 Cubism 导出包中保留两个逻辑 Rig，以统一接触、Draw Order 和运行时；这不意味着把小橘与星球焊成一个身体。
- 三视图先统一为一套近似 3D 骨架、质量块和关节范围，再投影到登录目标视角。
- 先证明姿势与动作，后生成一张结构连续的完整母版；所有拆层只从该母版内部产生。
- 文章中的“独立图层、三角网格、父子节点/矩阵级联、弹性节点、Action Tracer”用于 Cubism 阶段；生物、接触和力矩约束必须在它们之前完成。

## 2. 这次失败的根因

1. 把三视图当身份参考，而没有建立统一身体模型。
2. 先拆层和拼图，再补骨架、体积与力矩，顺序倒置。
3. 混用了登录原图头部、不同生成姿势的躯干和推断肢体；局部都像猫，整体不是同一只身体。
4. 用 alpha 重叠和少量骨段漂移指标代替生物连续性、支撑反力和全程视觉检查。
5. 在失败候选上继续补丁式修改，缺少一票否决与回退门禁。

## 3. 不可妥协的验收原则

- 只允许一套小橘身份、一套骨架比例、一套质量体积和一套左右肢体身份。
- 头、肋笼、腹部、骨盆不能因动作明显缩放或坍缩；接触压缩只能发生在表层软组织和毛发。
- 前肢运动必须由肩胛、肩、肘、腕、爪逐级产生；不得拉长、缩短或整体贴纸旋转。
- 胸腹与星球的接触法线、支撑反力、摩擦/滑动假设和释放时机必须明确。
- 眨眼、目光、眼睑跟随、耳朵、呼吸、尾巴、胡须和身体回稳是独立连续通道，不能靠整图切换。
- 任意中间帧出现断肢、重影、漂浮、穿插、关节翻面、体积塌陷或接触漂移，立即退回上一 Gate。

## 5. 新工作流与 Gate

### S0：冻结与清点

产物：权威输入、淘汰资产、目标动作、禁止事项清单。通过条件：任何后续素材都能追溯到唯一身份与唯一目标场景。

### S1：三视图统一身体（新增硬门禁）

产物：三视图同名解剖点、近似 3D 骨架、固定骨段长度、头/肋笼/腹部/骨盆质量块、关节活动范围和左右/深度关系。

通过条件：同一身体投影能解释三视图；不能为每个视图单独画一套“看起来合理”的骨架。

### S2：星球支撑与动作求解（新增硬门禁）

产物：Rest、遮眼中段、Cover 的重心、接触点、法线、反力、释放点、肩—肘—腕力矩方向，以及至少 41 采样点的 `0 -> 1 -> 0` 连通块面动画。

通过条件：骨段长度和质量块体积恒定；无 IK 分支翻转；胸腹始终有合理支撑；抬爪时身体有相反方向的低幅补偿；终点爪部与眼眶接触但不压塌头脸。

### S3：完整连续母版

只依据 S1/S2 的目标投影制作一只从耳尖到尾尖都连通的小橘。先验收无星球遮挡的完整身体，再叠回星球。不得从多个姿势或生成结果拼身体。

### S4：从单一母版内部拆层

按真实关节和遮挡拆出头脸、眼部、耳、颈胸、前肢各段、腹部、骨盆、后肢、四爪、尾巴与毛发。所有关节具备重叠纹理和隐藏补画。Rest 重组必须回到批准母版。

### S5：Cubism 结构与参数

应用文章的图层/网格/父子节点原则：ArtMesh 绑定独立视觉区域；Rotation Deformer 放真实关节；Warp Deformer 只做体积保持和表面形变；主动动作使用参数/Motion，Physics 仅做次级响应。

### S6：微动作与 Physics

独立实现眨眼、眼球九点目标、眼睑纵向跟随、眼先头后、呼吸错相、单耳注意、尾根主动与尾尖滞后、胡须/毛发余动、动作后回稳。状态切换保留参数值与速度。

### S7：运行时证明

网页只写 Live2D 参数。必须证明 Motion、Physics、Clipping、Draw Order 和混合在目标 WebView 真实执行；构建通过不能替代视觉证据。

## 6. 用户审批点

- 历史 M0 与原 Gate 2 保留为“当时已通过”，不抹掉。
- 因 Gate 3 证据推翻了原先的身体连续性假设，新增 `Gate 2B = S1 + S2`。
- 在 Gate 2B 通过前：禁止新图、禁止拆层、禁止 Photoshop/Cubism、禁止运行 v5 导入脚本。
- Gate 2B 交付只包含骨架/质量块/接触/动作块面证据，不消耗额度做写实生成。

## 7. 下一次执行范围

用户批准本 PRD 后，下一次只做 S1：基于三视图标注统一解剖点，并给出机器可读骨架与质量块合同。S1 图片先审核；未通过不进入 S2。S1/S2 均通过后才讨论新的完整母版。

## 8. 一句话硬规则

没有通过“三视图统一身体”和“星球支撑动作求解”两个新增 Gate，禁止生成母版、禁止拆层、禁止进入 Photoshop/Cubism，也禁止用像素重叠指标宣称身体连接成功。

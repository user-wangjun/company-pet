## 2. 不可压缩的骨架质量块

```text

└─ Neck cylinder
   └─ Ribcage ellipsoid
      ├─ Scapula_L/R sliding plates
      └─ Abdomen soft volume
         └─ Pelvis ellipsoid
            ├─ HindLeg_L/R
            └─ Tail root
```

以三视图头宽 `H = 1.0` 归一化：

| 质量块 | 屏幕投影宽 | 屏幕投影高 | Cover 状态最低保留 |

## 3. 接触压缩只发生在局部

- 星球只压缩胸腹下缘一条窄接触带，不能把整个躯干压成横向软垫。
- 肋笼、脊柱、骨盆与颈根不得通过 Warp Deformer 整体缩短来制造“趴下”。
- 毛发接触带最大法向压缩 `12–18%`；腹部软组织局部最大 `22%`；胸腔和骨盆最大 `10–15%`。
- 接触区外的二维网格局部面积变化以 `det(J)` 近似审计：主体保持 `0.90–1.10`，毛发接触带允许 `0.78–1.08`，不得翻转或趋近零。
- 压低高度时必须产生合理的侧向微扩张，而不是直接丢失体积。

## 4. 静力支撑

Cover 状态双前爪离开星球后，外部支撑来自胸腹、骨盆/收折后肢与星球：

```text
ΣF = R_chest + R_belly + R_hind - m g = 0
Στ_COM = r_chest × R_chest + r_belly × R_belly
       + r_hind × R_hind - r_g × m g = 0
```

- 爪贴脸属于身体内部接触，不能当成支撑全身的外力。
- 投影重心必须留在胸腹—后肢接触形成的支撑区域内。
- 若头部前倾增加，胸部反力与颈部/躯干反向配重应增加；不能靠拉长或压扁腹部抵消。

## 5. 前肢生物链

猫前肢建模必须包含 `scapula → upper arm → forearm → carpals/paw`，并分别保留肩、肘、腕关节；肩胛会在胸廓表面滑动，但不能脱离胸腔体积。

```text
Chest_Warp
└─ ScapulaSlide_L/R
   └─ Shoulder_Rot_L/R
      └─ UpperArm_Rot_L/R
         └─ Elbow_Rot_L/R
            └─ Forearm_Rot_L/R
               └─ Wrist_Rot_L/R
                  └─ Paw_Warp_L/R
```

- 主动作由目标角驱动，Physics 只叠加低幅余韵。
- 关节段长在 `rest → cover → rest` 中保持 `±3%`。
- 肩胛滑动量小于胸腔宽的 `6%`，且必须沿胸廓切向移动。
- 肘屈曲是遮眼弧线的主要来源；腕只在最后阶段小幅旋前/背屈。

依据：猫前肢的生物力学模型明确分为肩胛、上臂、前臂和腕掌四段，并以肩、肘、腕角及各肌群力矩描述；猫在负重坐姿下肘关节保持屈曲，肩胛平衡依赖胸廓与颈部肌肉产生的反向力矩。

## 6. 力矩与惯量

```text
tau = k * (theta_target - theta) - c * omega
alpha = tau / I
I_segment ~= m_segment * L_segment^2 / 3
```

- 抬爪时近端段先启动，远端段后随；不能四个关节同时等角速度旋转。
- 爪越远离肩轴，肩部所需力矩越大；因此自然动作会通过肘屈曲缩短力臂，而不是把整条前肢拉直。
- 两侧动作错开 `45–90 ms`；头部向先抬爪的反方向配重 `1.5–3.0°`。
- 胸腔和骨盆体积不得作为“缓冲器”大幅缩放；缓冲来自关节阻尼、毛发和软组织的局部形变。

## 7. Gate 3 拒绝条件

- 胸腔、腹部和骨盆合并成一个扁平横条，或颈根直接塌入腹部。
- 为了让爪接近脸而缩短前臂、扩大爪或隐藏肩肘结构。
- 前肢根部从脸侧、下颌或腹部直接长出，未连接胸廓上的肩胛与肩关节。
- 双爪抬起后没有胸腹/后肢支撑，投影重心落出支撑区域。
- 全身 Warp 的面积变化超出约束，或中间姿势出现局部网格翻转。

## 8. 生物逻辑硬约束

物理上“能连起来”不等于猫科动作成立。拆件和参数还必须保留下列生物结构：

- 肩关节位于肋笼上外侧，不能下沉到腹部或星球接触线；肩胛只沿胸廓表面滑动。
- 遮眼过程中肘始终保持同一屈曲侧。除非动作真实经过完全伸肘，IK 不得切换镜像解。
- 本镜头的肘夹角暂定安全区为 `35–140°`；这是小橘三视图和当前构图的工程边界，不冒充猫科通用医学极限。
- 爪接触脸时只允许趾垫和面部毛发局部压缩；颅骨轮廓、眼眶距离和前臂骨段长度不能跟着缩短。
- 抬爪顺序为肩胛前滑/肩屈 → 肘调整 → 腕和趾端贴合；回程相反并带低幅阻尼，不能整条前肢刚性平移。
- 双前肢离开支撑面后，胸腹与收折后肢必须继续承重；呼吸只能造成胸腹小幅周期扩张，不能替代姿势位移。
- 耳、眼、胡须、尾巴属于有生物时序的次级运动：受惊先耳后头，注视先眼后头，胡须和尾尖只做滞后响应。

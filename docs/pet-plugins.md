# 角色插件

应用只内置 `public/pets/index.json` 注册的公开角色。未注册的本地角色包可在开发服务器中预览，正式构建会删除这些包及全部素材，不进入安装包。

在“愈心”或“桌宠”页面点击“打开插件目录”，把解压后的角色目录放进去，再点击“刷新插件”。Windows 默认位置为 `%APPDATA%/com.yuxin.desktop/pet-plugins/`。刷新会通知平台窗口和桌面角色窗口；插件会按 `kind: "pet"` 或 `kind: "human"` 分别显示在“治愈”或“陪伴”页。

每个插件沿用现有角色包格式：`<角色 id>/pet.json` 及其引用的图片、动作、模型、对话和声音。目录名与清单 `id` 必须相同，使用小写英文、数字和短横线，不能与内置角色重名。清单中的资源路径相对于该角色目录；嵌套模型路径仍遵守原有包内解析规则。

当前支持 sprite 和 rig2d 数据角色包，资源接口只提供 JSON、PNG、JPEG、WebP、OGG、MP3、WAV，不执行插件脚本。暂不提供插件商店、ZIP 自动安装或授权码功能。私有角色不应分发给他人；普通数据包本身不提供复制保护。

源码交付和插件素材分别维护。忽略或停止 Git 跟踪只影响后续提交，已经进入旧提交或远程仓库的素材需要单独处理历史副本。

# v0.3.0 待办与提醒模块实现说明

本版本依据《愈心桌宠 v0.3.0｜待办与提醒模块详细 PRD》实现待办创建、状态流转、重复提醒、桌宠气泡、系统通知、今日回顾、回收站和宠物个性化反馈。

## 功能状态

待办与提醒现已作为主应用正式模块接入，不再作为独立预览功能：网页预览和 Tauri 桌面构建共用 `src/task-core/`、宠物反馈资源及系统提醒状态机。

账号页仍是未完成的本地实验原型，当前不接入主入口，也不进入正式安装包。构建阶段会剔除其 Live2D、登录插图和 Cubism 运行时素材；后续接入真实认证与邮件服务后再启用。

## 入口与界面

- 桌宠右键菜单：新建待办、今日待办、全部提醒、快速记录、主应用和设置。
- 快速创建：标题即可保存，支持回车；完整设置可在小窗内滚动。
- 主应用：今日四分区、全部、即将提醒、已过期、已完成、已取消、回收站和提醒设置。
- 完整字段：标题、备注、附件引用、截止时间、提醒时间、快捷提醒、重复规则、优先级、项目和加入今天。
- 详情操作：保存、完成、开始处理、延期、取消、关闭本次提醒、删除和恢复。

## 数据与提醒

- `src/task-core/types.ts` 定义任务、提醒模板、提醒实例、历史、设置和本地指标。
- `src/task-core/taskStore.ts` 负责持久化迁移、状态机、实例幂等、重复周期推进、仅本次操作、时区重算和30天回收站。
- 前端数据保存在 `localStorage` 的 `yuxin.tasks.v1`，第一版指标仅本地保存。
- Windows 使用任务计划程序 XML 为未来提醒注册后台唤醒，启用 `WakeToRun` 与 `StartWhenAvailable`，允许电池供电时启动且不限制主进程运行时长，并使用单实例插件把唤醒事件交给已运行的应用。
- Windows 原生通知提供已完成、10分钟、30分钟、1小时和查看详情操作；每个按钮使用带提醒实例 ID 的 `yuxin://` 深链接，因此应用退出后仍能重新启动并处理，且与桌宠气泡共享同一实例状态。
- 休眠期间错过多条提醒时，桌宠和系统通知都合并为一条“查看全部 / 关闭”汇总，不会误操作某个单独任务。
- 重复任务实例支持本次标题、备注、截止时间、优先级、项目、附件和提醒时间覆盖，模板与后续实例保持不变。

## 个性化关怀提醒

- 护眼、喝水、用餐和睡眠统一放在“提醒设置”页面；每张卡片的开关仅控制系统通知弹窗，桌宠动作和气泡始终保留。
- 护眼和喝水支持个人频率；早餐、午餐、晚餐和计划入睡时间支持独立设置。
- 设置保存在 `yuxin-care-reminders-v1` 本地数据中，旧版本数据会自动补齐默认设置。
- 运行时调度直接读取个人频率和时间；关闭系统弹窗不会停止桌宠提醒，用餐和睡眠仍保持每天一次的去重规则。
- 首次使用仅默认开启用餐和睡眠的系统弹窗；选择“以后不再提醒”后，说明会作为未读关怀来信永久保存在收件箱。
- 非 Windows 桌面端使用 Tauri 通知插件作为降级路径；浏览器预览使用 Web Notification API。

## 桌宠包资源

每个内置宠物包内都有：

- `three-view-preview.png`：三视图预览。
- `ART-BRIEF-v0.3.md`：三视图补绘要求与十类待办动作建议。
- `task-feedback.json`：创建、到点、完成、连续完成、延后、多次延后、延期、过期、多任务和每日回顾文案/动作映射。

宠物专属资源均留在 `public/pets/<pet-id>/`，平台只通过 manifest 的相对路径加载；资源缺失时退回通用动作或纯气泡，不阻断待办流程。

# 小星 Live2D：文章执行约束

依据用户指定的知乎文章《Live2D动画引擎的图形学原理及实现》以及小星的正面线稿、彩色三视图，后续生产固定遵守以下顺序。

## 从文章提取的硬约束

1. 先把每个可变形材料做成独立图层，再导出为同尺寸透明 PNG；不能把合成图直接当作模型材料。
2. 每个实际图层独立绑定网格；网格由三角形图元组成，变形依靠顶点和纹理坐标，而不是缩放整张人物截图。
3. 绘制前后关系由图层顺序控制；因此前发、脸、眼睛、后发、衣服与肢体必须明确归属，不能串材质。
4. 每个图层只归属一个主要节点；父节点的变换传递给子节点，不能用互相冲突的多父级补救错误拆层。
5. 柔软材料（主要是长发、衣摆）才进入弹性/物理；脸、眼白、鞋等刚性材料不滥加物理。
6. 视线与头部跟随依靠局部材料和网格变形；双眼必须拆成眼白、虹膜、瞳孔、高光、眼睑/眼线，而不是一张眼睛贴图。

## 对小星素材的落地规则

- `gate3-line-master-candidate-v1.png` 是正面几何和接缝的唯一像素基线。
- `gate3-color-target-v1.png` 只提供颜色、明暗和材质；不得覆盖线稿定位。
- 三视图用于判断后发体积、衣服厚度和遮挡后的连续结构，不把侧视或背视像素拼到正面。
- 所有生产层保持 512×1086 原始坐标；禁止非等比拉伸。
- 眼睛先做，且先通过 4 倍以上近景的源线稿叠合审查，再进入脸和头发。
- 手部每侧保持完整一层，不拆手指；当前动作范围不包含握拳或逐指动作。
- 每完成一组，只保留三类必要证据：源图近景、透明单层、层-only 重组。其余临时图不扩散。

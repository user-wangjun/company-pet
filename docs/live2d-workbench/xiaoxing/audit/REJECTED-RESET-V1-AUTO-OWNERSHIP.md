# Reset V1 自动线稿归属：工作自审否决

日期：2026-07-23  
决定人：Codex 工作自审

`qa/reset-v1-head-line-ownership-review.png` 和
`model/reset-v1/head-line-ownership/` 不得提升为语义线稿母版。

否决原因：

1. 自动区域判定仍会把衣服、项链或印花笔画混入侧发及待判定层。
2. 仅切分原线稿可见像素，无法产生完整闭合的后发、脸底和眼部材料。
3. 前发与后发的真实遮挡关系不能依赖亮度阈值或大范围多边形猜测。
4. 虽然所有 PNG 是完整 512×1086 画布，仍不满足“实际绘制或 1:1
   生成完整材料”的要求。

后续改为：依据原始线稿逐个绘制闭合语义轮廓；可见纹理仍从原彩稿原坐标
1:1 取用，隐藏范围单独补画。首先重新确定双眼的真实坐标和眼裂曲线。

# V3 双眼重画候选已废弃

`qa/v3-eye-material-review.png` 及其生成的 `model/working-v3/eyes/*.png` 没有进入 Photoshop 工作母版，已移入 `audit/rejected-v3-eye-reconstruction/`，只作错误记录，不得继续派生。

废弃原因：候选把原始双眼“重新设计”为较规则的杏眼，导致眼裂高度、眼白面积、虹膜比例、上下眼线曲率均与小星彩稿不同。它满足了材料数量，但破坏了角色身份，不能继续派生。

后续规则：

1. 默认睁眼必须从 `gate3-color-target-v1.png` 的原像素拆出。
2. 所有默认可见层重新合成后，必须与原彩稿眼睛做像素差异审查。
3. 只允许补画被上眼睑遮挡、为了虹膜移动所需的不可见上缘；补画不得改变默认显示结果。
4. 在像素回组审查通过前，不导入 PSD，不生成眨眼或视线参数。

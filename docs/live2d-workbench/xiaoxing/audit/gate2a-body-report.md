# Gate 2A：小星统一身体预检

## 决策摘要

当前三视图能够由同一套近似身体比例解释，没有发现必须为某个视图另造一套骨架的证据。
Gate 2A 的工程预检和用户视觉确认均已通过。本结论允许进入 Gate 2B 姿势与支撑预检，
仍不允许直接进入正式拆件或绑定。

遮挡，因此远侧关节位置属于统一身体的推断，不是直接可见证据。

## 身体体积合同

- 头部：以头骨体积而不是发型轮廓为基准；前发和后发均为外层材质。
- 胸腔：正背面宽、侧面窄，保持椭圆柱体积；宽松 T 恤不承担骨架功能。
- 骨盆：位于 T 恤下摆和裙腰遮挡区；腿根必须从骨盆连续连接。
- 脊柱：头、颈、胸腔、骨盆使用一条连续中轴；身体摆动不得通过缩短躯干实现。
- 接触：首版站姿双脚接地，脚底高度锁定；身体轻摆不得让脚底漂移。

## 左右与遮挡

- `L/R` 始终按角色自身左右命名，不按观看者左右命名。
- 正面时角色右侧显示在画面左边；背面时对应关系反转。
- 侧面图朝画面左侧，近侧和远侧肢体不得合并成一个活动层。
- 后发位于头部与背部衣服之间；前侧发束位于脸、颈部和 T 恤之前。

## 动作边界草案

- 头横转：视觉约 `-20° ~ +20°`
- 头俯仰：约 `-12° ~ +12°`
- 头侧倾：约 `-8° ~ +8°`
- 身体横摆：约 `-6° ~ +6°`
- 身体侧倾：约 `-4° ~ +4°`
- 手臂：首版仅小幅陪伴动作，不做大幅抬臂或挥手

这些数值用于保护现有三视图身份，不代表 Cubism 参数已经建立。

## 自审发现

1. 三个视图的头顶、下巴、颈根、肩、肘、腕、髋、膝、踝和地面高度能够合理对应。
2. 正背肩宽一致，腿段长度一致，没有明显的视图间骨长冲突。
3. 侧面头骨中心相对头发轮廓稍向面部方向偏移，这是头骨与后发体积不同造成的预期现象。
4. 袖口、长发、T 恤下摆和裙腰仍遮挡关键连接区，必须在生产线稿中明确补画。
5. 叠加图中的椭圆是体积约束，不是最终 ArtMesh 边界，也不是要画进角色的可见轮廓。

## Gate 2A 决定

**工程自审：通过。用户视觉门禁：通过。**

批准证据：用户在查看三视图骨架叠加图后回复“是的”。

下一步在获得用户确认后，建立正面生产母稿方案与完整语义边界，不直接从三视图裁切部件。

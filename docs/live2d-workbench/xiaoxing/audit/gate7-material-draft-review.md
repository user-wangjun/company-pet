# Gate 7 可见素材草稿自审

## 结论

本轮从同一张 512×1086 正面彩色母稿中导出 26 个全画布 RGBA 草稿层，用于验证拆图坐标、透明通道和分组流程。它们不是最终 Cubism 材料。

## 已通过

- 所有草稿均保持母稿坐标，不发生裁切偏移。
- 所有文件均为 512×1086 RGBA PNG，未使用绝对运行时路径。
- 草稿层 id 全部属于现有 62 层合同。
- 左右手仍各为一个完整手层，没有重新生成逐指材料。
- 头发、袖臂、衣裙、腿袜鞋均能单独显示并重新合成。

## 尚未完成

- 头顶、侧发根部、袖口内侧、裙腰、裙下大腿和袜口仍需要隐藏补画。
- 当前多边形只用于确定拆图区域，边缘尚未做最终逐像素清理。
- 脸、五官、项链、身体隐藏底层和嘴部尚未纳入本轮 26 层草稿。
- 未建立正式 Cubism ArtMesh、参数关键形和 Physics。

这些缺口已在 `gate7-material-draft-contact-sheet.png` 中用红框标出，禁止将当前草稿误标为完成素材。

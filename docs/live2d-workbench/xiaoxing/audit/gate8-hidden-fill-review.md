# Gate 8 隐藏补画候选自审

本轮没有调用生成式图像工具，也没有修改正式导出清单；只从同一张正面母稿邻近区域复制或取平均色，生成 12 个隐藏补画候选。

## 视觉处理

- 头发根部使用邻近黑发纹理，避免把脸部或眼睛带入隐藏区。
- 袖口内侧使用同侧袖子纹理，左右袖分别检查。
- 肩线后方衣身使用衣身平均色，避免复制头发或印花。
- 裙下大腿和袜口使用同材质邻近区域，保持肤色和袜子色调连续。
- 每个候选都保留为独立全画布 RGBA 文件，便于后续替换或删除。

## 结论

候选可以用于下一步“活动层移动不露白”的结构测试，但仍不是最终修复。头发、衣身和裙腰的纹理连续性还需要在正式绘图工具中逐像素清理；候选不得直接进入 Cubism 正式工程。

# Gate 2B：小星待机重心移动预检

## 动作定义

本轮只验证一种低幅度待机动作：双脚保持接地，身体向角色右侧轻移，再回到原位，
形成 `0 → 1 → 0` 的连续过渡。它不是最终 Motion，也不包含头发或衣服 Physics。

- 采样数：41（含起点、目标点和回归点）
- 骨盆最大水平移动：约 8 px
- 骨盆最大垂直移动：约 3 px
- 双脚踝位置：锁定
- 体积椭圆：固定尺寸，仅整体平移/小幅旋转
- 远端肢体：使用同一弯曲分支，避免 IK 翻转

重心代理值仅用于验证支撑关系，不是人体动力学测量；它由头、胸腔、骨盆和四肢的粗略质量
权重组成。实际 Cubism Physics 仍应作为二级响应，不得决定核心脚底、手部或视线轨迹。

## 自审观察

1. 目标帧仍保留完整躯干、骨盆和双腿连接，没有通过缩短骨段来制造位移。
2. 膝盖在目标帧向统一弯曲分支小幅偏移，回程连续，没有突然换侧。
3. 双脚支撑线固定，重心紫色投影始终落在支撑区内。
4. 头、胸腔、骨盆沿同一连续身体块移动；没有把动作拆成互不相连的整姿势图片。
5. 这个动作幅度适合小星的安静陪伴气质；更大的动作需要重新做支撑预检。

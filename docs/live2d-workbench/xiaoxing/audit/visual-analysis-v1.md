# 小星素材视觉分析 v1

## 总结

现有两张 `1448 × 1086` RGB PNG 足以锁定小星的角色身份，并支持下一步三视图身体预检；
它们不是可直接导入 Cubism 的分层原画。最稳妥的路线是以正面视图建立一张新的、坐标锁定的
生产母稿，以侧面和背面作为体积、发型、服装和隐藏区域参考。

## 角色识别锚点

- 偏写实的日系少女比例，头部和五官不宜被做成夸张 Q 版。
- 黑色长直发，刘海较碎，两侧发束落到胸前，后发覆盖肩背并在中背处形成尖碎轮廓。
- 浅色宽松落肩 T 恤，前胸有黑色英文字样和蝴蝶印花。
- 黑色短百褶裙、白色堆堆袜、浅色厚底运动鞋。
- 双腕饰品和小型颈链吊坠是容易丢失但辨识度较高的细节。
- 表情安静、克制；嘴形小，眼神偏柔和，不适合默认做成高能量夸张表情。

## 有利条件

1. 正面、侧面、背面均为近似直立中性姿势，适合建立统一身体坐标。
2. 三个视图的脚底、头顶和主要服装高度大体可对应，能做地标叠加。
3. 手臂与躯干留有间隙，正面轮廓没有完全黏在身体上，后续拆臂比贴身姿势更容易。
4. 彩稿与线稿构图高度一致，自动审计仅检测到预期的近似重复，没有发现损坏文件。
5. 侧视图提供了额头、鼻尖、嘴唇、下巴、胸腹、臀部、膝盖与鞋子的前后体积依据。
6. 背视图明确了后发、衣服背面、裙褶和鞋后结构。

## 需要先解决的不一致与歧义

### 1. 三视图不是严格正交投影

绘画三视图存在自然的透视和再绘制差异。鞋、手和发梢不能按像素直接对应，必须先定义同一套
头骨、胸腔、骨盆和肢体长度，再投影回三个视图验证。

### 2. 正面脸不能直接变形成完整侧脸

侧视图适合约束头部体积，但常规 Live2D 头部 `Angle X` 应保持小角度转动。若强行从正面连续
变到 90° 侧脸，会导致眼睛、鼻口和脸轮廓出现不可接受的压扁或身份漂移。

### 3. 长发遮挡非常重

必须至少分离后发底层、左右侧发、刘海和若干前发束，并补全后脑、双耳、耳后脸侧、颈部、
肩线和衣领。整片长发只挂一个物理组会像橡胶布；需要按区域设置不同的响应与阻力。

### 4. 宽松 T 恤遮住真实躯干

衣服轮廓不能直接充当身体骨架。需要先建立胸腔、腰腹、骨盆的隐藏体积，再让衣服作为外层材质
跟随。袖口下还需补齐完整肩根和上臂，否则抬臂时会出现洞或圆形补丁。

### 5. 前胸印花是高风险形变区

蝴蝶和文字具有明显直线与识别结构。若把它们烘焙在整件 T 恤网格上，大幅胸腰形变会让图案
扭曲。建议把印花做成独立层或受限贴花层，只跟随低频衣服形变。

### 6. 五官素材目前完全烘焙

眨眼和视线至少需要独立的眼白、虹膜、瞳孔、高光、上下眼睑与闭眼线；嘴部需要独立口线、
口腔和必要的上下唇/嘴角控制。仅从当前整图切出眼睛不能得到可靠的隐藏眼球与闭眼形状。

### 7. 手部与饰品细而复杂

手指、手链和吊坠在桌面缩放后容易闪烁或糊成一团。首版宜保持手臂小幅动作，将饰品做轻量的
次级摆动；若要求大幅挥手，需单独重绘手部并提高局部网格密度。

## 建议的首版模型边界

- 保留全身外观，但动作以低幅度陪伴型待机为主。
- 头部横转建议先控制在约 `-20° ~ +20°` 的视觉范围，俯仰和侧倾更小。
- 身体只做呼吸、重心轻移和很小的肩胯反向摆动。
- 头发、衣摆、裙褶、吊坠和手链做独立次级物理，不承担核心动作轨迹。
- 首版不做完整转身、走路、大幅抬臂或正面到侧面的整姿态切换。

## 进入下一门禁前需要的证据

1. 三视图头顶、下巴、颈根、肩、肘、腕、胸腔、骨盆、膝、踝和脚底地标叠加。
2. 一套统一的身体段长、体积、左右身份和前后遮挡合同。
3. 正面生产母稿的画布范围，以及全身/半身显示策略。
4. 用户确认角色识别锚点和上述首版动作边界。

## 当前结论

**可继续，但不能直接绑定。** 素材质量足以做高质量的人形 Live2D 前期设计；真正的工作量主要在
生产母稿、完整拆件和隐藏区域补画，而不是网格本身。

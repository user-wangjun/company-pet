# V2 重置复核

## 为什么重置

用户指出的三个问题成立：

1. Gate 4 眼睛草稿是手工估计坐标，没有逐层回到线稿实际眼裂边界。
2. Gate 5 为了排版把不同宽高的裁剪区域统一拉到固定尺寸，审查图本身发生了非等比变形。
3. Gate 6–9 继续使用这些不可靠的坐标，导致后续素材草稿和补画继承错误。

## 文章中的正确顺序

知乎文章明确把流程放在：线稿/上色 → 每个图层导出独立 PNG → 每层建立三角网格 → 画家算法绘制顺序 → 每层一个节点和单一父节点 → 父子变换传递 → 弹性节点与动作追踪。

因此，动作合同和物理示意不能替代正确的图层边界；示意多边形也不能直接变成生产遮罩。

## V2 执行规则

- 线稿是分层边界的唯一依据，彩稿只校验颜色和身份。
- 所有审查图使用原始 512×1086 比例；局部放大只允许等比例整数放大。
- 每层先生成独立 RGBA PNG，再单独审查透明边界；不先做全身叠加示意。
- 眼睛必须重新从线稿眼裂、眼白、虹膜、瞳孔和上下眼睑逐层定位。
- 手部仍按用户要求粗分：完整手层 + 独立手链，不制作逐指动作。
- Gate 4–10 的旧输出保留为历史证据，但不再进入生产链。

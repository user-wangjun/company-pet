# V5–V15 材料链整体退回

日期：2026-07-23  
决定人：用户（视觉否决）

## 结论

`model/xiaoxing-material-master-v15.psd` 及其所有派生物不再是小星的生产
基线。V5–V15 的默认合成数值检查没有证明独立材料完整、贴合线稿或保持角色
身份；用户复核确认材料母版本身已有缺失，头发和眼睛分层粗糙，后续结果继续
放大了这些问题。

以下内容全部降级为历史失败证据，不得继续修补或派生：

- `qa/v5-*.png` 至 `qa/v15-*.png`
- `model/working-v5/` 至 `model/working-v15/`
- `model/xiaoxing-material-master-v15.psd`
- `model/xiaoxing-rig-v1.cmo3`
- `audit/authoritative-status-v5.json` 至 `audit/authoritative-status-v15.json`

文件暂时保留，仅用于追溯失败原因，不代表可用材料。

## 根因

1. 把“默认位置重新合成无差异”误当成“每个独立材料完整且正确”。
2. 遮罩主要由颜色和区域启发式生成，没有先完成并通过逐线贴合的语义线稿母版。
3. 头发发束、脸底、眼裂、眼白、虹膜等边界在低分辨率近似中被粗化。
4. 隐藏补全和可见像素所有权混在同一轮处理，局部缺失可被默认遮挡掩盖。
5. 审查图缩放过小，数值门禁又只验证联合结果，无法暴露孤立图层的缺口和串材质。

## 新的停止条件

重新开始时只允许使用以下原始素材：

- `source/xiaoxing-three-view-line.png`
- `source/xiaoxing-three-view-color.png`

正面母版必须是原图的整数坐标裁切，禁止缩放、重绘、降采样或生成式替换。
接下来先提交中文高倍率线稿母版审查，逐项证明轮廓、头发、双眼、领口、四肢
和鞋袜均未缺失。该门禁获得用户明确通过前，不生成纹理分层 PSD，不进入
Cubism。

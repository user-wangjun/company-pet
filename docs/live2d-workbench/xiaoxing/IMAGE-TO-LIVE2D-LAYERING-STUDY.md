# 小星：从单张图片到 Live2D 可用分层的学习结论

## 学习范围

本文只处理一件事：怎样把现有的单张线稿/彩稿，制作成能够导入 Live2D Cubism 并安全变形的分层素材。

不在本文范围内：动作表演设计、Physics 参数、运行时接入、登录页交互、桌宠功能或特效。

## 官方流程给出的核心结论

依据 Live2D 官方的 [Illustration Processing](https://docs.live2d.com/en/cubism-editor-tutorials/psd/)、[About Material Separation](https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/)、[Notes on PSD Creation](https://docs.live2d.com/en/cubism-editor-manual/precautions-for-psd-data/) 和 [Preparing to Move the Illustration](https://docs.live2d.com/en/cubism-editor-tutorials/import/)：

1. **分层不是从扁平图中裁出可见像素。** 每个会独立运动的部件都要成为完整素材，被别的部件挡住的部分需要重新补画。
2. **先决定运动，再决定拆分粒度。** 头发至少区分后发、刘海和左右侧发；脸部拆眼、眉、鼻、嘴、脸底和耳朵；身体按实际动作拆脖子、躯干、手臂、手和腿。
3. **工作 PSD 与导入 PSD 是两份不同用途的文件。** 工作 PSD 保留组、蒙版和可编辑绘制层；导入 PSD 中每个实际部件合并为一个图层。
4. **Cubism 导入层必须“一部件一图层”。** 一个部件的线稿、填色、阴影和效果在导入 PSD 中要合并；如果阴影需要独立运动，才把它作为独立部件。
5. **导入 PSD 的基础格式是 RGB、8 bit/channel、sRGB。** 图层名保持唯一，导入版不保留图层蒙版。
6. **PSD 图层进入 Cubism 后才成为 ArtMesh。** 网格要完整包住该层像素；眉毛、睫毛和嘴等大变形部件需要手工控制网格形状和密度。

## “从单张图分层”的正确操作模型

原始平面图只能提供三种证据：

- 可见轮廓：当前画面中真正看见的边界。
- 表面材质：颜色、阴影、线条和纹理应该长什么样。
- 遮挡关系：谁在谁前面，以及哪个部件的隐藏部分需要补全。

它不能直接提供被遮住的完整部件。因此，生产过程应当是：

```text
原始线稿和彩稿
  -> 确定动作需求与语义部件
  -> 为每个部件描出完整边界
  -> 补画被遮挡区域
  -> 每个部件在原画坐标中独立绘制
  -> 仅用这些部件重组原始静止画面
  -> 拉开部件检查隐藏区域和接缝
  -> 制作一部件一图层的导入 PSD
  -> 导入 Cubism，逐层建立 ArtMesh
```

“描出完整边界”不是用套索沿当前可见边缘裁切。例如：

- 刘海移开后会露出额头，所以脸底必须在刘海下面继续完整绘制。
- 虹膜移动时会露出更多眼白，所以眼白必须在虹膜后面补完整。
- 头部转动时脖子会上移并被露出，所以脖子必须向上补到接近嘴部。
- 手臂摆动时袖口会露出上臂根部，所以手臂需要伸进袖子内部。
- 裙子移动时会露出裙内腿部，所以左右腿必须在裙子下面连续延伸。

## 小星当前原画的建议分层

下面是“能完成自然眨眼、眼球移动、轻微头转、呼吸、头发摆动和小幅身体动作”的首版粒度。没有动作价值的装饰线不单独拆层。

### 头发与头部后层

1. `hair_back_base`：完整后发体积，包含脸和侧发后面被挡住的连续区域。
2. `hair_side_screen_left`、`hair_side_screen_right`：左右脸侧长发；只在需要不同摆动时独立。
3. `ear_screen_left`、`ear_screen_right`：完整耳朵，补齐被发丝遮挡的耳轮。
4. `face_base`：完整圆润脸底，只含皮肤、脸轮廓和必要底色，不烘焙眼睛、眉毛、刘海或耳朵。

### 五官

每只眼分别拆：

- `eye_white_*`：完整眼白，范围比默认可见区域大。
- `iris_*`：虹膜。
- `pupil_*`：瞳孔；只有确实需要独立缩放/表情时才单拆。
- `eye_highlight_*`：高光；只有需要独立跟随或闪烁时才单拆。
- `eyelash_upper_*`：上眼线/睫毛。
- `eyelid_lower_*`：下眼睑线。
- `eye_close_fill_*`：闭眼时用于遮住眼球的肤色或闭眼结构，不能拿脸底裁片冒充。

其余五官：

- `brow_screen_left`、`brow_screen_right`
- `nose`
- `mouth_upper`
- `mouth_lower`
- `mouth_inner`
- `tongue`（首版确实需要张嘴时才制作）

### 头发前层

1. `bangs_center`
2. `bangs_screen_left`
3. `bangs_screen_right`
4. 可独立摆动的少量前发束；不把每根发丝机械拆成一层。

刘海和前发的每一层只拥有自己的线条与材质，不能把眼睛、眉毛或脸底像素一并裁进去。

### 身体与衣物

1. `neck`：向上补到接近嘴部，向下伸入领口。
2. `torso_tshirt`：衣身，包含衣服主体线稿与填色。
3. `shirt_print`：只有需要与衣服不同的变形控制时才独立；否则合并入衣身。
4. `sleeve_screen_left`、`sleeve_screen_right`
5. `arm_upper_screen_left`、`arm_upper_screen_right`
6. `arm_forearm_screen_left`、`arm_forearm_screen_right`
7. `hand_screen_left`、`hand_screen_right`：首版保持整只手，不逐指拆。
8. `bracelet_screen_left`、`bracelet_screen_right`
9. `skirt`
10. `leg_screen_left`、`leg_screen_right`
11. `sock_screen_left`、`sock_screen_right`
12. `shoe_screen_left`、`shoe_screen_right`

手臂是否保留“上臂/前臂”两段，最终由首版动作决定。如果只做很小的整体摆动，可合并为左右完整手臂；如果要明显屈肘，则必须分段并补足肘部重叠。

## 小星当前必须补画的隐藏区域

| 部件 | 必须补全的区域 | 主要检查动作 |
| --- | --- | --- |
| 脸底 | 刘海、侧发和眼睛下方的完整皮肤 | 刘海移开、头转、眨眼 |
| 后发 | 脸、耳朵和前发后面的连续发量 | 头转、侧发摆动 |
| 耳朵 | 发丝遮挡的耳轮和耳根 | 侧发移开、头转 |
| 眼白 | 虹膜、眼睑遮挡区域 | 视线左右/上下移动 |
| 脖子 | 下颌后方和领口内部 | 头部旋转与上下移动 |
| 上臂 | 袖子内部的肩侧延伸 | 手臂摆动 |
| 前臂/手 | 袖口、手链下面的连续皮肤 | 手臂摆动、手链跟随 |
| 左右腿 | 裙子内侧与袜口内部 | 裙摆和腿部小幅移动 |

补画必须沿用相邻区域的线宽、肤色、阴影方向和材质流向。圆形色块、镜像复制、径向填充或仅够默认姿势遮住空洞，都不算完成。

## 推荐 PSD 结构

工作文件：`xiaoxing-layer-source-working.psd`

```text
00_参考_锁定
10_后发
20_身体后层
30_脸底与耳朵
40_眼睛
50_眉鼻嘴
60_衣身与四肢
70_前发
80_配饰
90_QA标记_不导出
```

工作 PSD 内每个部件可保留：原图副本、组蒙版、补画层、线稿层、颜色/阴影层。导入 PSD 则把每个最终部件合并为一个唯一命名的像素层，并移除 QA 标记、参考层和未应用蒙版。

## 在进入 Cubism 前必须通过的验收

1. **静止重组**：只用正式部件层合成，肉眼与原目标一致；不能保留完整人物底图兜底。
2. **单层纯度**：单独显示任一层时，不含其他语义部件，例如刘海层不能带眼睛像素。
3. **隐藏区域检查**：把刘海、侧发、头、手臂、裙子分别拉开，下面没有透明洞、重复轮廓或材质断层。
4. **接缝压力检查**：部件在计划动作幅度内移动后，肩、肘、腕、领口、裙腿和袜口仍连续。
5. **坐标不漂移**：所有工作层保持同一 512×1086 画布与原始位置，不靠导入后手工缩放拼回角色。
6. **导入 PSD 检查**：RGB、8 bit/channel、sRGB、唯一图层名、一部件一图层、无未应用图层蒙版。
7. **Cubism 回组检查**：导入后默认参数状态与 PSD 静止重组一致。
8. **ArtMesh 检查**：每个网格完整包住该部件像素；眉、睫毛和嘴使用适合变形方向的手工网格。

## 对当前工作包的判断

现有 `model/xiaoxing-line-separation-working-v1.psd` 只有锁定参考层和空分组，还没有实际完成任何正式部件素材。因此：

- 现有多边形、色块、候选遮罩和像素裁片只能作为边界讨论或失败记录；不能提升为可绑定分层。
- 下一步不应继续眼睛参数、网格或 Physics。
- 正确的下一门禁是：先完成一个小范围但完整的“正面头部分层样例”，同时提供静止回组与拉开检查。
- 该样例通过后，再使用相同方法拆全身，最后才制作 Cubism 导入 PSD。

## 正面头部样例的通过条件

首个学习验证样例至少包含：后发、脸底、左右耳、左右侧发、三组刘海、左右眉、双眼各自的眼白/虹膜/上眼线/下眼睑，以及鼻和闭口结构。

它必须证明：

- 默认回组不改变小星的脸型、眼型、五官位置与头发轮廓；
- 前发和侧发移开后，脸底、耳朵和后发完整；
- 虹膜移动时眼白连续；
- 任何一层都不夹带另一部件；
- 所有层可以在原始坐标直接叠回，不需要缩放或猜位置。

只有这份样例通过用户视觉复核，才说明“单张图片分层”已经真正掌握，可以继续全身生产。

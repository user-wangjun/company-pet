# 阶段 A：画面右侧手臂骨架修正候选 V2

## V1 为什么失败

V1 的肘点 `(368,425)` 几乎等于肩 `(332,261)` 到腕 `(393,533)` 的直线在
`y=425` 处的横坐标 `368.78`。这不是从肘部形态得到的结构，而是把三个旧比例点
直接连成了近直线。

同时，原彩稿在 `y=425` 的主要可见皮肤范围约为 `x=341～374`，中心约
`x=357.5`。V1 的肘点靠近皮肤外缘，没有落在肘部体积中心。

## V2 骨架

| 地标 | 坐标 | 依据 |
| --- | ---: | --- |
| 肩 | `(332,261)` | 袖内肩关节推断 |
| 肘 | `(357,425)` | 肘高皮肤横截面中心、线稿轮廓与人体提携角 |
| 腕 | `(393,533)` | 手链下腕关节估计 |

修正后：

- `L1 = 165.894545 px`
- `L2 = 113.841996 px`
- 上臂全局角：`81.332613°`
- 前臂全局角：`71.565051°`
- 相对肘角：`θ2 = -9.767562°`

在画布 `+y` 向下的约定里，负 `θ2` 表示画面右臂的前臂相对上臂继续向画面外侧
偏。这样上臂较直、前臂向外，不再是一根直杆。

## 修正后的动作范围

- `θ1`：`73.332613° ～ 89.332613°`
- `θ2`：`-27.767562° ～ -3.767562°`

整个范围保持 `θ2<0`，不跨过直线分支。主动作仍为 41 样本确定性

## 与候选轮廓无关的集合证明

设：

- `A` 为 V6 冻结最低包络在局部 `s <= 22 px` 的中性栅格；
- `U` 为 V6 冻结可见上臂所有权；
- `P` 为任意待建正式前臂。

冻结条件要求 `A ⊆ P`，因此 `A∩U ⊆ P∩U`。当前直接从两份冻结栅格得到：

- `|A| = 1177`；
- `|U| = 544`；
- `|A∩U| = 416`。

所以任何包含 `A` 的正式前臂都满足 `|P∩U| >= 416`，而唯一静态像素
所有权要求 `|P∩U| = 0`。两者矛盾。

这个矛盾不依赖本轮手臂外轮廓候选、腕线、手链、手部代理或未来纹理；即使不采用
“超出原始轮廓 `132` 像素”这一辅助判断，冻结集合之间的冲突仍然成立。

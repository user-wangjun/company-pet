# V7-C 用户视觉审查清单

## 本次批准范围

本次只批准正式前臂纯色几何、F1–F5 责任划分、临时手部最低根部包络，以及已展示的肘腕覆盖结果。

不批准纹理、PSD、Cubism、Physics、Runtime，也不代表正式手部已经完成。

## 请审查

1. `qa/V7-C-PRODUCTION-FOREARM-F1-F5-BOARD.png`
   - 红色 F1 肘根是否自然；
   - 青色 F2 是否保持原稿前臂；
   - 紫色 F4 在手部移开时是否只是合理的腕部隐藏延伸；
   - 手链移开后是否仍有完整皮肤。
2. `qa/V7-C-FORMAL-ELBOW-THREE-ANGLES.png`
   - 最弯、中性、近伸直的粗细是否一致自然；
   - 是否存在尖刺、突出或骨裂。
3. `qa/V7-C-FORMAL-ELBOW-SLOW-SCAN.gif`
   - 肘根是否连续收窄并确定性回中；
   - 是否出现抽动或局部鼓包。
4. `qa/V7-C-WRIST-THREE-ANGLES.png`
   - 腕角 `-8° / 0° / +12°` 是否自然；
   - 极值时露出的少量紫色 F4 是否可接受。
5. `qa/V7-C-WRIST-SLOW-SCAN.gif`
   - 腕扫是否连续；
   - 手链移开条件下是否仍无透明裂缝。
6. `qa/V7-C-FULL-CHAIN-ELBOW-WRIST-3X3.png`
   - 肘×腕组合极值是否仍保持一条完整手臂。
7. `qa/V7-C-DISPLACED-PART-INTEGRITY.png`
   - 上臂、手部、手链分别移开后，前臂材料是否完整且没有借遮挡藏缺口。

## 同时需要批准的合同替换

旧 V6 临时前臂代理与中性源所有权已经被证明静态冲突，因此没有把它偷偷塞回正式前臂，也没有修改 V6 文件。

本次需要批准的替换是：

`旧静态最低代理包含义务 → 源像素写保护的 F1 动态肘根 + 已批准的连续收窄规则 + 41/6/241 全域结果验证`

这项替换会在以下情况自动失效：

- 肘点、腕点、骨长或角度范围变化；
- F1/F4 或连续收窄规则变化；
- 进入 Cubism 后没有重跑组合域；
- 正式手部不包含当前临时手根包络。

如果全部可以接受，请回复：

`批准 V7-C 正式前臂几何、临时手根包络和肘根合同替换`

批准后将执行最终证据审计与冻结；不会继续制作正式手部或任何纹理。

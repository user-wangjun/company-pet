## 5. 已证明的第一层矛盾

把 V6 冻结临时代理限制到局部 `s <= 22 px`，得到集合 `A`：

- `|A| = 1177 px`；
- `A` 中有 132 px 位于权威源图人体轮廓之外；
- `A` 与冻结的可见上臂所有权集合 `U` 重叠 416 px；
- `|U| = 544 px`。

原合同同时要求：

- `A ⊆ P`，其中 `P` 是正式前臂；
- `P` 绘制在 `U` 上方；
- `U` 保持不可变的可见上臂所有权；
- `P ∩ U = ∅`，因为静态像素所有权必须唯一。

但由 `A ⊆ P` 且 `|A ∩ U| = 416`，任何 `P` 都必然满足：

`|P ∩ U| >= 416`

这与 `P ∩ U = ∅` 直接矛盾。

因此，不存在同时满足全部旧条件的静态正式前臂。

## 7. 两个失败尝试——只作为反例，不是限定选项

### 失败尝试 B：为了通过旧指标而转移肘部所有权

曾从一组阈值候选中选择：

- 前臂局部根部阈值约为 `s >= -15.25 px`；
- 前臂向肘后延伸约 15.245902 px；
- 从 544 个冻结可见上臂像素中，将 384 px 转给前臂，约占 70.6%；

- 旧扫描结果达到缺口 0、断开 0、内弯异常暴露 0。

但视觉预检发现，被转移的 384 px 形成一个随前臂旋转的明显楔形色块。这个楔形会重写用户已批准的可见肘线，看起来像一个移动补丁。它属于“数值通过但材料所有权和视觉失败”，没有获得用户批准。

### 失败尝试 A：保留已批准肘线，只检查联合覆盖连续

- 上臂转给前臂：0 px；
- 上臂裁切：0 px；
- 可见肘线不变；
- 上臂与前臂联合覆盖的透明缺口：0；
- 断开样本：0。

但：

- 前臂自身向肘后延伸为 0 px，不满足旧“前臂必须至少承担 15 px”；
- 旧“内弯异常暴露”最多为 4569 个 4× 子像素；
- 若要判定通过，必须重写合同。

工程人员曾过早建议采用这个方案，并把合同改成“联合覆盖连续即可”。这是一次偏航：它没有先证明 15 px 应由哪种几何承担，也没有证明旧“内弯上臂暴露”究竟是视觉裂缝还是正常上臂可见区域。

## 8. 需要区分的四个概念

请特别检查旧合同是否错误地把下列四件事合并成了一个静态代理：

1. **中性可见像素所有权**  
   决定权威彩稿中的每个可见像素属于上臂还是前臂，必须唯一，并保留用户批准的肘线。

2. **完整材料的隐藏解剖几何**  
   上臂和前臂各自被遮挡部分的连续延伸，可在部件移开时显示，但不应改变中性可见所有权。

3. **动作扫掠中的遮挡责任**  
   在肘部转动时，哪个材料在什么角度负责防止透明裂缝；它未必等于中性可见像素所有权。

4. **验证指标中的异常暴露**  
   真正需要禁止的应是背景透明缝、断开、尖刺、鼓包或不合理材料翻转，而不一定是“看到任意上臂像素”。

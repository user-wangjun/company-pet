# 完整袖子小节完成审计

## 目标

画面右侧袖子不能只保留外侧可见裁片；它必须是可独立移动的完整袖筒，隐藏内侧具有连续几何和纹理。

## 逐项证据

| 要求 | 证据 | 结论 |
| --- | --- | --- |
| 袖子不再只是外侧可见裁片 | R9 锁定遮罩包含新增隐藏内侧；新增区域 1827 像素 | 已满足 |
| 顶部不能过宽 | R4 用户否决已记录；R9 保留收窄落肩袖山 | 已满足并获用户批准 |
| 袖口下端对齐且圆滑 | R7 修正局部交点，R8-R9 加入局部连续圆角 | 已满足并获用户批准 |
| 几何必须为单块连续材料 | 工程审计 `alphaConnectedComponents = 1` | 已满足 |
| 隐藏区域必须有真实连续纹理 | 本地布料拟合、约束调和延拓、袖口线延续；无均色、径向、镜像或重复克隆 | 已满足 |
| 纹理不得改变批准几何 | 工程审计 `alphaMatchesLockedR9Exactly = true` | 已满足 |
| 可信原图袖面不得漂移 | 工程审计 `trustedSourceRgbPreserved = true` | 已满足 |
| 不得有洞或轮廓外溢 | 隐藏区域全覆盖，轮廓外 alpha 像素为 0 | 已满足 |
| 隔离和大位移后仍自然 | 三张纹理 QA；用户回复“可以，补完之后没什么问题” | 已满足 |

## 最终决定

完整袖子几何与纹理小节通过。该决定仅覆盖袖子材料，不批准上臂、PSD、Cubism、Physics 或 Runtime。

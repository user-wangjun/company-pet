# 完整袖筒最终材料

## 当前状态

本目录是本轮唯一保留的完整袖筒交付目录。最终袖子几何已由用户批准并锁定；纹理仅在该锁定遮罩内部补全被头发和衣身遮挡的内侧袖筒，不改变 alpha、袖宽、袖山或袖口轮廓。

## 方法

- 保留已确认的可信原图袖面像素；
- 在新增隐藏区域使用本地布料色面拟合与约束调和延拓；
- 重建旧可见裁片外边界附近的非可信窄带，避免完整袖筒内部残留拼接暗线；
- 依据锁定袖口边界延续两条低对比度袖口结构线；
- 仅在新增外轮廓添加语义描边；
- 未调用外部生成服务，未上传原图，未使用镜像、重复克隆、径向填充或均色块。

已批准的判断范围：

- 新增内侧是否像同一块白色布料；
- 原袖面与新增内侧之间是否还有拼接暗缝、灰块或重复纹理；
- 袖口线是否自然延续；
- 大位移后仍为完整、无洞、无裁断的独立袖子。

上述批准仅关闭完整袖子材料小门禁，不批准完整上臂、PSD、Cubism、Physics
或 Runtime。

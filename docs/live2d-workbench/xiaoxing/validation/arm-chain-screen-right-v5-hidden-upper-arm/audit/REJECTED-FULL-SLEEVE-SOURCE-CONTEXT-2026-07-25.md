# 全袖源图上下文裁片作废

日期：2026-07-25  
决定来源：用户视觉反馈

## 结论

此前真实纹理运动预览把冻结 V4 的袖子几何遮罩直接用于裁取扁平正面彩稿。该几何范围内包含被头发、衣身和其他前景覆盖的源图像素；这些像素被错误烘焙进袖子上下文，随袖子一起运动，造成视觉分裂。

因此以下结论作废：

- “冻结袖子几何遮罩裁出的 RGB 可以作为袖子运动材料”；
- 使用该全袖 RGB 上下文生成的 41 帧、6 极值、`±ε`、移开和闪烁视觉预览；
- 基于这些预览作出的视觉通过判断。

数值几何覆盖证明不依赖这份 RGB 裁片，仍可保留；但必须使用新的语义纯净视觉上下文重跑纹理 QA。

## 修订边界

本轮不制作完整袖子纹理。新的视觉 QA 只允许使用袖口接缝附近的局部安全条带：

1. 同时受上臂局部坐标范围约束；
2. 只保留与袖子织物颜色特征一致的源像素；
3. 已批准的袖口混合带和接缝责任集继续保留；
4. 头发、衣身及其他不属于袖子的源像素不得进入移动条带。

该条带只能称为“袖口接缝 QA 上下文”，不得称为完整袖子材料。

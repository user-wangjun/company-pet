# 小星画面右侧手臂单链验证 V1

## 当前状态

`阶段 A 设计候选：等待用户视觉确认`

本目录只验证画面右侧（角色左臂）的：

`sleeve → upper_arm → forearm → hand`

当前批次仅冻结权威输入、骨架、动作范围、可见像素归属规则、逆覆盖搜索规则和
中文视觉审查图。尚未生成四个纯色材料，尚未补画隐藏纹理，尚未制作 PSD 或
Cubism 工程。

## 坐标与命名

- 画布：`512×1086`。
- 原点：画面左上角。
- `+x` 向画面右，`+y` 向画面下。
- 角度使用该画布坐标系中的度数，逆时针/顺时针含义不得套用数学 `+y` 向上的
  默认解释。
- 为避免旧合同左右命名歧义，本目录只使用 `screen_right`，并显式记录
  `character_side: left`。

## 本门禁的通过范围

用户确认 `qa/skeleton-design-review.png` 后，只能说明：

1. 选侧、肩肘腕落点和骨长可作为阶段 A 的固定设计；
2. 动作范围足以进行几何证伪，没有先缩小到不可检验；
3. 四材料的父子关系、Draw Order 和接缝覆盖责任已定义。

它不能说明纯色材料、隐藏纹理、ArtMesh、Cubism 或 Runtime 已通过。

## 停止条件

- 用户未通过当前骨架审查图；
- 肩、肘或腕落点需要修改；
- 动作范围只能靠缩小来避免断裂；
- 手链遮挡被用于掩盖腕部接缝；
- 任一材料只能裁出当前可见像素，无法满足逆覆盖范围。

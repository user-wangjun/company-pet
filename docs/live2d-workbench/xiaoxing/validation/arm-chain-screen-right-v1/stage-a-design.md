# 阶段 A：画面右侧手臂几何设计候选

## 当前决策

- 验证侧：画面右侧，角色左臂。
- 验证链：`sleeve → upper_arm → forearm → hand`。
- 画布与原图坐标：`512×1086`，不缩放、不重定位。
- 当前仅提交设计；四个纯色材料尚未生成。

## 骨架候选

| 地标 | 正面母图坐标 | 证据性质 |
| --- | ---: | --- |
| 肩 | `(332, 261)` | 袖子遮挡下的解剖推断 |
| 肘 | `(368, 425)` | 可见轮廓与三视图比例联合估计 |
| 腕 | `(393, 533)` | 手链遮挡下的关节中心估计 |

固定骨长候选：

- `L1 = 167.904735 px`
- `L2 = 110.855762 px`

解析 FK 骨长容差为 `0.01 px`；渲染端点容差为 `0.25 px`。任何动作都不得通过
修改这两个长度完成。

## 动作范围

画布使用 `+y` 向下的角度约定：

- 默认 `θ1 = 77.619243°`
- 默认 `θ2 = -0.652599°`
- `θ1` 允许范围：`69.619243° ～ 85.619243°`
- `θ2` 允许范围：`-0.652599° ～ 23.347401°`

主动作从默认姿势运动到：

- `θ1 = 69.619243°`
- `θ2 = 17.347401°`

再按同一确定性曲线返回默认位置，共 41 个样本。肘只使用 `θ2` 增大的同一弯曲
分支，不允许跨分支翻转。范围四角会作为主路径之外的组合极值单独检查。

## 父子关系

```text
torso_anchor（范围外）
└─ shoulder_rotation
   ├─ sleeve
   ├─ upper_arm
   └─ elbow_rotation
      ├─ forearm
      └─ wrist_rotation
         └─ hand
```

Draw Order 从后到前：

`upper_arm → forearm → hand → sleeve`

Draw Order 只决定遮挡，不得代替隐藏材料覆盖。

## 手链处理

手链不加入本轮四材料，也不参与源图差异评分。腕部必须在隐藏手链的审查图中保持
完整连接；另提供仅作参照的原手链叠加图。不得因为默认姿势中手链遮住缝隙而判定
腕部通过。

## 用户本轮需要判断的内容

请查看 `qa/skeleton-design-review.png`：

1. 画面右侧选臂是否正确；
2. 肩、肘、腕中心是否符合原画；
3. 固定骨长连接是否自然；
4. 动作范围是否足够检验，又没有超出“小幅陪伴动作”；
5. 手链排除规则是否清楚。

只有这张图获得明确通过，才生成阶段 A 的四个全画布纯色材料。

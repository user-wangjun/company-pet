# 小星单臂工作流自动化原型 V11

当前状态：发布事务修复候选已获用户明确批准并重新冻结。当前批准记录与
`audit/v11-freeze-manifest-2026-07-27.json` 共同绑定本入口、配置、输出、报告和
上游 V10 冻结清单；任何锁定工件的字节变化都会重新打开 V11 门禁。

本目录提供一个真实可运行的统一入口，把已冻结的 V4–V10 单侧手臂工程样本按固定
依赖顺序重新准备和验证。它是自动复核与确定性复现工具，不是完整素材生成器。它只
写入本目录的临时运行目录和 `output/`，不会回写任何 V10 或上游冻结文件。

## 运行

```powershell
python run_v11.py
```

只核对冻结输入、不生成输出：

```powershell
python run_v11.py --verify-only
```

成功时进程退出码为 `0`，标准输出为机器可读 JSON，完整结果写入
`output/audit/v11-result.json`。失败时退出码为 `1`，标准错误输出包含机器可读失败
对象；此前成功的 `output/` 不会被替换。

## 执行链

1. 校验 V10 冻结清单自身哈希、38 项锁定工件的路径、长度与 SHA-256，并核对六个
   上游冻结清单哈希。
2. 读取 `config.json`。
3. 分别清空两个互相独立的临时运行目录。
4. 在两个目录中各自完整准备四个全画布材料和哈希锁定的 Cubism 导入 PSD。
5. 两次分别重算 41 个 FK 回程样本与 6 个组合极值，并与冻结 V4 样本对照。
6. 两次分别检查骨长、三处相邻材料接缝、整条链断开、像素回程及冻结网格数值。
7. 两次分别生成最小审查板和单次检查结果。
8. 对两次材料、PSD、FK 样本和审查图逐项比较字节数与 SHA-256；最终汇总报告在
   比较通过后生成，不参与自引用比较，且不写入时间或临时路径。
9. 在第一份临时目录内写完最终机器结果和中文报告，并复核候选输出的 7 项确定性
   工件；任何最终汇总写入失败都发生在正式输出切换之前。
10. 只有全部一致时才执行带旧输出回滚保护的事务式目录切换；切换事务内再次校验
    候选输出和 V10 的 38 项工件，成功后不再写入 `output/`。任一差异都会返回非零
    退出码、报告首个差异，并恢复此前正式输出。

## 证明边界

V11 证明的是工程自动化和重复验证，不重新批准纹理、几何、完整角色、Physics、
Runtime 或平台接入。由于 CMO3 是专有工程文件，网格阶段复核哈希锁定的 V10 逐网格
数值审计；它不会把该复核描述为重新提取 CMO3 顶点或重新操作 Cubism GUI。

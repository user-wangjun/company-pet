# 阶段 A：画面右侧手臂骨架高度修正候选 V3

## 为什么 V2 仍不通过

V2 肘点 `(357,425)` 虽然消除了直杆，但仍沿用旧预检的肘高。固定肩、腕后，
它得到的上臂/前臂长度比约为 `1.46`，视觉上表现为上臂偏长、前臂偏短，肘点偏低。

## V3 选择

肘点改为 `(355,415)`：

- 正好位于原彩稿 `y=415` 可见皮肤横截面 `x=339～371` 的中心；
- 比 V2 上移 `10 px`、向身体内侧移动 `2 px`；
- 上臂/前臂长度比变为约 `1.26`；
- 保留约 `9.36°` 的自然外偏折角；
- 没有为了得到比例而改变肩点、腕点或缩短动作范围。

## V3 动作范围

- `θ1`：`73.505624° ～ 89.505624°`
- `θ2`：`-27.355943° ～ -3.355943°`
- 主动作目标：`θ1=73.505624°`、`θ2=-19.355943°`
- 41 样本确定性 `0→1→0`，无 Physics。

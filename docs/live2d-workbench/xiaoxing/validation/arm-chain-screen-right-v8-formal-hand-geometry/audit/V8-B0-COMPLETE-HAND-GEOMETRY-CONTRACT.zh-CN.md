## H1-H4 分区

### H1：冻结可见手部

`H1 = V_hand`。它是已经批准的可见手部源像素，坐标和 RGB 不得改变。H1 继续
保持与袖子、上臂、前臂和手链的可见所有权交集为 `0`。

### H2：冻结最低隐藏腕根

`H2 = E_hand \ V_hand`，共 `81 px`。这 81 px 在中性可见所有权中属于前臂/手链，
但在当前前臂含手链位于整手之上的层序下，登记为整手在后方的隐藏材料责任。

H2 不改归 `V_hand`，不改变可见所有权，不让手链承担皮肤接缝覆盖。V8-B1 的
`M_hand` 必须包含 H2。

### H3：逆覆盖新增隐藏腕根

H3 是 H1/H2 固定后，为满足腕角全域皮肤接缝覆盖而需要新增的最小隐藏腕根。
H3 只能位于腕根许可区域，不能扩展到掌部、手指、指尖或指缝拓扑区。

H3 禁止通过以下方式产生：

- 直接并集所有运动后的手部轮廓；
- 用形态学闭合填死指缝；
- 手工圆形补丁；
- 楔形尖刺；
- 让腕根变成明显粗腕或色块。

### H4：腕部双向覆盖 QA 区

H4 只用于 QA，不是材料，不是可见所有权，不输出为独立腕部层。H4 不能用来
证明手链承担了腕缝皮肤覆盖。

正式材料方程只允许是：

```text
M_hand = H1 ∪ H2 ∪ H3
```

## 389 px 包络规则

V8-B1 生成的正式完整手部必须满足：

```text
E_hand ⊆ M_hand
```

这是一条静态局部包含规则，不能用运动覆盖替代。若 `M_hand` 不包含全部 389 px，
则 V7 腕部结论自动失效，必须重开腕部合同。

## H3 逆覆盖方法

V8-B1 中求 H3 时，按以下顺序执行：

1. 对每个合法腕角样本计算腕缝皮肤责任区；
2. 隐藏手链后再判断腕缝是否由皮肤几何覆盖；
3. 找出 H1/H2 和前臂皮肤仍不能覆盖的目标像素；
4. 将这些目标像素逆变换回冻结手部局部坐标；
5. 只把至少一个合法样本真实需要的局部像素加入 H3 候选；
6. 应用腕根局部性、连通性、孔洞和指缝保护约束；
7. 重跑全域采样；
8. 做删除审计：任何删掉后仍通过全部采样和拓扑检查的 H3 像素都不得保留。

本阶段最多允许声明“采样域内删除审计后的最小或近似最小”，不得声称已经证明
连续参数域的全局最优。

- 慢速腕部运动视觉审查。

自适应加密触发条件：

- 腕缝透明缺口；
- 隐藏手链后皮肤覆盖失败；
- 前臂/手部出现未批准的可见穿插；
- M_hand 断成多个连通分量；
- 出现孔洞、尖刺、圆块、粗腕或轮廓碰撞；
- 0→1→0 回程不确定。

停止条件：

- 所有基础样本通过；
- 所有触发区间已二分到声明的腕参数容差内，且相邻样本不再出现新的失败分类；
- H3 删除审计不能再删除任何像素；
- 确定性重新生成差异为 `0`；
- 中文视觉审查通过。
